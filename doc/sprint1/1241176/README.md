* **Building Dimensions:** $400m × 150m = 60 000m²$

## 2. Network Outlets Calculation

**Standard Rule:** Two outlets per 10m² of work area (`outlets = Work Area * 2`)
* **NOTE:** `Work Area = room area / 10`
